How to fix images missing alt text

WCAG 1.1.1 (Non-text Content)

What is wrong

Screen readers cannot describe an image that has no alt attribute, and search engines learn less about the page.

How to fix it

Give every meaningful image a short alt that says what it shows or does. Use an empty alt (alt="") for purely decorative images so they are skipped.
